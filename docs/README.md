# docs/

Design documents, progress log, and heuristics review.

## Files

| File | Committed | What it contains |
|---|---|---|
| `DESIGN.md` | Yes | The system design contract. Covers all three stages, the task format, the harness, the report, and the ecosystem adapter interface. The authoritative spec for pipeline behavior |
| `PROGRESS.md` | Yes | Per-session build log and handoff notes. Records what was built, test counts, review outcomes, and open items |
| `HEURISTICS_REVIEW.md` | Yes | Author's review sheet for every threshold in `pipeline/config.py`. Groups values by whether they fired on the target repo, never fired, or changed from the original proposal |
| `decisions-raw.md` | No (local) | Raw dump from the design session. Present on disk but not tracked in git |

## Not here

- `HEURISTICS.md` (threshold documentation): repo root
- `REPORT.md` (pipeline output): repo root (generated by `pipeline/report/`)
- Design session log and review-round summaries: `transcripts/dev/`
